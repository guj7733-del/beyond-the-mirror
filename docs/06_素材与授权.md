## 测试模型的授权

仓库 README（日文与英文）写明：

- 个人用途、商业用途均可自由使用；
- 可以再分发、出售包含这些数据的 VRM 文件或改动后的数据；
- 不需要联系作者，不需要署名或标注授权；
- 作者不提供针对个别用途的授权确认，使用者自行判断并承担责任；
- 数据中包含的第三方权利（例如模型基于的 VRoid Studio 官方模型）以及所用服务、软件的条款，需要另外遵守。

VRM 文件内嵌的 meta 字段与 README 不一致：

| 字段 | 值 |
|---|---|
| licenseName | Redistribution_Prohibited |
| allowedUserName | Everyone |
| commercialUssageName | Allow |
| violentUssageName / sexualUssageName | Allow |
| contactInformation | @hinzka |

本地运行、研究录屏、Poster 展示都在 README 允许的范围内。如果要把整个项目（含模型文件）公开发布，建议二选一：发布时去掉 `public/models/` 下的测试模型，让使用者自行下载；或者在发布说明中引用 README 的授权原文，并注明文件内 meta 字段与之不一致。

研究者替换成自己的角色后，也需要核对该模型的授权。程序在“调试 → 模型检查 → 授权字段”中原样显示 VRM 的授权字段，GLB 文件没有这些字段。

## 测试用视频（未包含在项目中）

自动测试时用 Pexels 上的两段免费视频代替真实摄像头：一段正面说话的视频（Pexels 视频编号 8048249），用来测试张嘴、微笑和眨眼；一段转头的视频（编号 5474326），用来测试头部转向。视频只在开发电脑上转成 MJPEG 文件喂给 Chrome 的虚拟摄像头，没有放进项目。[05 验收记录](05_验收记录.md) 中的摄像头截图来自第一段视频。研究者录制 Poster 演示时应使用自己的摄像头画面。
